# EginAI

**Бидай ауруларын фото бойынша ерте анықтау** · **Раннее выявление болезней пшеницы по фото**

Фермер жапырақты немесе масақты суретке түсіреді. EginAI бірнеше секундта ауруды анықтайды және модель белгілерді көрген аймақты көрсетеді. Қорғау шаралары қазақ және орыс тілінде беріледі. Келісім берілсе, жағдай аурулар картасына түседі. Веб-қосымша мен Telegram-бот арқылы жұмыс істейді.

Конкурс «AI autumn» 2026, бағыт: **Агротех, экология және ақылды қала**. Команда — С. Сейфуллин атындағы ҚАТЗУ.

## Іске қосу / Запуск (жюри үшін)

Docker Compose v2 ғана керек. / Нужен только Docker с Compose v2.

```bash
git clone https://github.com/raissov01/eginai.git eginai && cd eginai
docker compose up --build
```

Браузерде ашыңыз / Откройте: **http://localhost:8000**

- 8000 порты бос болмаса: `APP_PORT=8080 docker compose up --build`
- Сынақ фотолары: `samples/` (әр класқа бір-екі сурет)
- Telegram-бот (міндетті емес): `cp .env.example .env`, `BOT_TOKEN` жазып, `docker compose --profile bot up --build`
- ИИ-жауаптар (міндетті емес): `.env` ішінде `ANTHROPIC_API_KEY`. Кілтсіз сұрақтарға білім базасы жауап береді.

Модель (`backend/app/model/eginai.onnx`) репозиторийде бар, қайта үйрету қажет емес.

## Мүмкіндіктер / Возможности

| | |
|---|---|
| Диагноз | 7 класс: қоңыр тат, сары тат, ақ ұнтақ ауруы, масақ фузариозы, масақ септориозы, сау жапырақ, сау масақ |
| Түсіндіру | CAM жылу картасы: модель қай жерге қарады; зақымданған аудан бағасы |
| Адал белгісіздік | өсімдік емес фото немесе сенім төмен болса — «қайта түсіріңіз» және top-3 нұсқа |
| Кеңес | белгілері, шекті деңгей, агро- және химиялық шаралар (әсер етуші зат тобы), мерзімі, алдын алу — kk/ru |
| Сұрақ-жауап | білім базасы бойынша BM25 іздеу (RAG) + қалауы бойынша Claude |
| Карта | келісіммен, ~1 км дәлдікпен, фото сақталмайды |
| Арналар | веб (мобильді) + Telegram-бот |

## Сапасы / Качество

Тест жиыны модель оқу кезінде көрмеген суреттерден тұрады. Бөлу әр сурет бойынша жасалған. Метрикалар `ml/metrics.json` файлында, қателер матрицасы `materials/figures/confusion.png` суретінде.

**Accuracy 97.1% | macro-F1 96.7%**  (n = 580), CPU-да бір сурет ≈ 57 мс.

Модель сенімсіз болса, «қайта түсіріңіз» деп жауап береді: тест суреттерінің 2,2%-ы осылай белгіленді, ал модель сенімді болған жағдайларда дәлдік 98,4%.

| Класс | Precision | Recall | F1 | Тест суреттері |
|---|---|---|---|---|
| Масақ фузариозы / Фузариоз колоса | 0.99 | 0.98 | 0.99 | 125 |
| Масақ септориозы / Септориоз колоса | 0.88 | 0.97 | 0.92 | 36 |
| Сау масақ / Здоровый колос | 0.97 | 0.95 | 0.96 | 81 |
| Сау жапырақ / Здоровый лист | 0.96 | 0.98 | 0.97 | 66 |
| Қоңыр тат / Бурая ржавчина | 0.97 | 0.97 | 0.97 | 107 |
| Ақ ұнтақ / Мучнистая роса | 0.97 | 0.94 | 0.96 | 102 |
| Сары тат / Жёлтая ржавчина | 1.00 | 1.00 | 1.00 | 63 |

## Архитектура

```
Телефон / браузер ──► FastAPI (/api/predict) ──► ONNX Runtime: EfficientNet-B0
       │                     │                      ├─ logits → 7 класс
Telegram-бот ──HTTP──┘       │                      └─ features → CAM жылу картасы
                             ├─► kb/diseases.yaml (kk/ru) ─► BM25 ─► [Claude, кілт болса]
                             └─► PostgreSQL: тек келісілген жағдайлар (ауру, күн, ~1 км орын)
```

| Қалта | Мазмұны |
|---|---|
| `ml/` | датасет құрастыру, үйрету (PyTorch + timm), ONNX экспорт, бағалау |
| `backend/` | FastAPI, инференс, кеңестер, дерекқор, тесттер |
| `bot/` | aiogram 3 Telegram-боты |
| `web/` | React + Vite + Leaflet |
| `kb/` | аурулар бойынша білім базасы (kk/ru) |
| `replica/` | аналогтар мен пайдаланушы пікірлерін талдау |
| `materials/` | түсініктеме жазба, презентация, сызбалар |

## Модельді қайта үйрету / Переобучение модели

```bash
python3.12 -m venv .venv-ml && source .venv-ml/bin/activate
pip install -r ml/requirements.txt
# датасет (1.1 ГБ, CC-BY-4.0)
mkdir -p data/raw/wheat_det && for i in 0 1 2; do curl -L -C - -o data/raw/wheat_det/train-$i.parquet \
  https://huggingface.co/datasets/Project-AgML/wheat_disease_detection/resolve/main/data/train-0000$i-of-00003.parquet; done
python -m ml.prepare_data            # бокстарды қиып → data/cls/{train,val,test}
python -m ml.train --epochs 15       # GPU 4 ГБ жеткілікті, ~15 мин
python -m ml.export_onnx             # → backend/app/model/
python -m ml.evaluate                # → ml/metrics.json, materials/figures/confusion.png
```

## Қауіпсіздік және деректер / Безопасность и данные

- Кодта кілт/құпия сөз жоқ, тек `.env` (git-ке кірмейді), үлгісі `.env.example`.
- Фото дискке де, базаға да жазылмайды. Картаға тек келісіммен диагноз, күн және 2 ондық белгіге дейін дөңгелектелген координата жазылады.
- Жүктеу шегі 10 МБ. Бүлінген немесе сурет емес файлға түсінікті 4xx жауап беріледі. Декомпрессия бомбасынан қорғаныс, IP бойынша сұраныс шегі бар.
- Контейнер root емес пайдаланушымен жұмыс істейді.
