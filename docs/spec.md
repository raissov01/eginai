# EginAI — спецификация (конкурс «AI autumn»)

Источники: `materials/Программа конкурса ИТ проектов.doc` (критерии), `materials/zayavka_EginAI.docx` (заявка).

## Что строим
Фермер фотографирует поражённое растение пшеницы → система за ≤5 с определяет болезнь,
показывает, где на фото признаки (тепловая карта), оценивает долю поражённой площади и
выдаёт рекомендации на казахском и русском. С согласия пользователя случай ставится на
карту очагов.

Каналы: веб-приложение (React + Leaflet) и Telegram-бот (aiogram).

## Честный объём MVP (против заявки)
| В заявке | В MVP | Почему |
|---|---|---|
| EfficientNet + YOLOv8 | EfficientNet-B0 + CAM (карта активации классов) | YOLOv8 — AGPL-3.0; CAM даёт локализацию без ручной разметки боксов |
| ≥8 классов, пшеница и ячмень | классы открытого полевого датасета пшеницы + «здоровое» | ячменного полевого датасета под классификацию нет; ячмень — этап 2 |
| собственные фото с полей | открытый датасет (CC-BY-4.0) | в ноябре поля убраны; сбор своих фото — весна 2027 |
| LLM + RAG | RAG по базе знаний (BM25) + опционально LLM (Claude), без ключа — офлайн-шаблон | «запускается у жюри без доработок» |

## Требования конкурса → как закрываем
- Рабочий прототип: `docker compose up` поднимает БД, API+веб; бот — при наличии токена.
- Читаемый код с комментариями, тесты (pytest), README с запуском.
- Лицензия: MIT для кода, `THIRD_PARTY.md` — все датасеты/библиотеки/модели с лицензиями.
- Безопасность: ключи только в `.env` (в git — `.env.example`), фото не хранятся,
  координаты — только с явного согласия и округляются до ~1 км.
- Материалы: пояснительная записка 5–15 стр., презентация 7–12 слайдов, видео 2–5 мин.

## Нефункциональные
- Ответ `/api/predict` ≤ 5 с на CPU (ONNX Runtime).
- Интерфейс kk/ru, казахский по умолчанию.
- Битое/не-изображение/огромный файл → понятная ошибка 4xx, никогда 500.
