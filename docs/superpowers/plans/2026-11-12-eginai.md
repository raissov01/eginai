# EginAI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native, chosen by the user: "бәрін өзің жаса"). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Working wheat-disease diagnosis prototype (web + Telegram bot + outbreak map) with kk/ru advice, runnable by the jury with one `docker compose up`, plus competition materials.

**Architecture:** Offline ML pipeline (`ml/`) turns an open field dataset into a classification set, fine-tunes EfficientNet-B0 and exports ONNX with two outputs (logits, last feature map) so the API computes CAM without gradients. FastAPI (`backend/`) serves `/api/*` and the built React app; PostgreSQL stores consented cases only. The bot (`bot/`) is a thin HTTP client of the API.

**Tech Stack:** Python 3.12, PyTorch + timm (training only), onnxruntime, FastAPI, SQLAlchemy 2 + psycopg, rank-bm25, anthropic (optional), aiogram 3, React 18 + Vite + TS + react-leaflet, Docker Compose.

**Spec:** `docs/spec.md`

## Global Constraints
- Classes = `ml/classes.json` (written by Task 1); every component reads it, never hard-codes.
- Model file `backend/app/model/eginai.onnx` is committed (≤ 25 MB) so the jury needs no training.
- No secrets in git; `.env.example` only. Without `ANTHROPIC_API_KEY` / `BOT_TOKEN` the system still runs.
- Photos are never written to disk/DB. Coordinates stored only with `consent=true`, rounded to 2 decimals.
- Default language `kk`; every user-facing string exists in `kk` and `ru`.
- Upload limit 10 MB; accepted: JPEG/PNG/WebP/HEIC-decoded-by-Pillow.

## Review Focus
1. Non-image or corrupted upload → 415/422 with kk/ru message, not 500 (test in Task 3).
2. Photo with no plant (wall, face) → low confidence → "unsure, retake" answer instead of a confident wrong disease (threshold test in Task 3).
3. Huge image (e.g. 8000×6000) → resized, still < 5 s (test in Task 3).
4. `consent=false` with coordinates → nothing stored (test in Task 4).
5. DB down at start → API still predicts; map endpoint returns 503 (test in Task 4).

### Task 1: Dataset builder
**Files:** Create `ml/prepare_data.py`, `ml/classes.json`, `tests/ml/test_prepare.py`
**Interfaces:** Produces `data/cls/{train,val,test}/<class>/*.jpg`, `ml/classes.json` = `[{"id": str, "kk": str, "ru": str}]`.
- [ ] Test: `crop_with_margin(img(100x100), bbox=[10,10,20,20], margin=0.25)` returns 30×30 crop clamped to image; `sample_background(boxes, size)` returns a box not overlapping any bbox (IoU 0).
- [ ] Implement: read parquet shards, crop each bbox with 25 % margin (min side 64 px) into its class folder; sample up to 1 background patch per image as `healthy` (green-dominant check: mean G > R and G > B); keep the original `split` column for train/val/test.
- [ ] Run on real data, print per-class counts, commit.

### Task 2: Train + export
**Files:** Create `ml/train.py`, `ml/export_onnx.py`, `ml/evaluate.py`, `ml/requirements.txt`
**Interfaces:** Produces `backend/app/model/eginai.onnx` with outputs `logits[1,C]`, `features[1,1280,7,7]`; `backend/app/model/classifier.npy` (`[C,1280]` weights) + `bias.npy`; `ml/metrics.json` (`accuracy`, `macro_f1`, per-class P/R/F1), `materials/figures/confusion.png`.
- [ ] timm `efficientnet_b0` pretrained, 224 px, AdamW, label smoothing 0.1, class-balanced sampler, Albumentations (flip, rotate, color jitter, random resized crop), AMP, batch 32 (GTX 1650 4 GB), ≤ 15 epochs, early stop on val macro-F1.
- [ ] Export ONNX opset 17; verify ONNX logits == torch logits (atol 1e-3) in `export_onnx.py`.
- [ ] Evaluate on test split, write metrics + confusion matrix, commit.

### Task 3: Inference core + predict API
**Files:** Create `backend/app/inference.py`, `backend/app/main.py`, `backend/app/schemas.py`, `backend/tests/test_predict.py`
**Interfaces:** `Predictor.predict(image_bytes: bytes) -> Prediction(top: list[(class_id, prob)], unsure: bool, cam_png_b64: str, affected_pct: float)`; `POST /api/predict` (multipart `file`, query `lang`) → JSON with prediction + `advice`.
- [ ] Tests: corrupted bytes → 422; text file → 415; 8000×6000 JPEG → 200 and < 5 s; uniform gray image → `unsure is True` (max prob < 0.55 OR entropy high); valid crop from test split → top-1 matches label.
- [ ] Implement: EXIF transpose, resize 224, normalize ImageNet; CAM = ReLU(W[c]·F) upsampled, normalized; `affected_pct` = share of pixels with CAM > 0.5 (documented as estimate); overlay PNG (jet-free colormap: transparent→orange) as base64.

### Task 4: Cases DB + map API
**Files:** Create `backend/app/db.py`, `backend/app/cases.py`, `backend/alembic`-free `create_all` on start, `backend/tests/test_cases.py`
**Interfaces:** `POST /api/cases {disease, confidence, lat, lon, consent, source}`; `GET /api/map?days=30` → GeoJSON FeatureCollection of points + `GET /api/stats`.
- [ ] Tests (SQLite in tests): consent false → 204 nothing stored; lat out of range → 422; coords rounded to 2 decimals; DB unavailable → `/api/map` 503, `/api/predict` still 200.

### Task 5: Knowledge base + advice (RAG)
**Files:** Create `kb/diseases.yaml`, `backend/app/advice.py`, `backend/tests/test_advice.py`
**Interfaces:** `advise(class_id: str, lang: Literal["kk","ru"], question: str | None) -> Advice(title, symptoms, actions, timing, prevention, sources, generated_by: "kb"|"llm")`.
- [ ] KB per class: kk+ru name, symptoms, conditions, measures (agrotechnical, biological, chemical by active-ingredient group — no doses, "по регистру пестицидов РК"), timing, prevention, sources (FAO/CIMMYT/extension pages).
- [ ] BM25 retrieval over KB chunks for free-text questions; LLM (claude-haiku-5-5) only if key set, answer grounded in retrieved chunks; on any LLM error → KB template.
- [ ] Tests: every class has kk+ru fields; no key → `generated_by == "kb"`; question "сары дақ" retrieves rust chunks.

### Task 6: Web app
**Files:** `web/` (Vite React TS): pages Diagnose, Map, About; i18n `web/src/i18n.ts`.
- [ ] Diagnose: drag/drop or camera capture, result card (disease, confidence bar, unsure state, CAM overlay toggle, affected %, advice sections), consent checkbox + geolocation → POST /api/cases.
- [ ] Map: react-leaflet + OSM, points colored by disease, filter by disease/days.
- [ ] Flat design (solid colors, 1 px borders, no gradients/emoji), fonts with full Kazakh glyphs (verify with fontTools), mobile first.
- [ ] Build served by FastAPI `StaticFiles` at `/`.

### Task 7: Telegram bot

- [ ] Without `BOT_TOKEN` the container exits 0 with a log line (compose profile `bot`).
