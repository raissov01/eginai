# Recon: «фото листа → диагноз → совет» у аналогов EginAI

Дата: 12.11.2026. Режим: облегчённый (только ядро, без полного инвентаря приложений).
Источники: публичные страницы магазинов, сайты разработчиков, FAO Agritech Observatory, пресса. Аккаунты аналогов не создавались, скриншоты не сохранялись.
Обозначения: **[факт]** — видно на странице-источнике; **[вывод]** — выведено из описаний и отзывов; **[не проверено]** — источник не найден.

## 1. Объём

- Срез: одно ядро — фермер фотографирует лист пшеницы/ячменя → модель называет болезнь → совет по защите → (у EginAI) точка на карте очагов по району.
- Для кого: фермеры и агрономы Северного Казахстана (СКО, Акмолинская, Костанайская, Павлодарская обл.), языки kk/ru, канал — Telegram + веб.

## 5. Поток F01 «фермер проверяет больной лист»

```
F01  S01 выбор культуры -> S02 камера -> S03 проверка качества -> S04 анализ -> S05 диагноз -> S06 совет
     провалы: S03 отклоняет фото; S05 «не знаю» -> S07 сообщество (платно / без ответа)
     счёт кликов (оценка): 4–5 нажатий + первичный выбор культур + регистрация
```

Для EginAI в Telegram: отправить фото боту → ответ ≤ 5 с (болезнь, уверенность, тепловая карта признаков, доля поражения, совет kk/ru) → с согласия — точка на карте очагов (округление ~1 км). Цель — 1 действие (отправить фото) + 1 необязательное.

## 8. Размер
Ядро EginAI: 3–4 экрана в веб-приложении + 1 сценарий бота + карта. Сложные места: (1) датасет казахстанских фото пшеницы/ячменя в полевых условиях; (2) честная обработка «не уверен» (калибровка, топ-3, отказ); (3) модерация точек на карте (геолокация до района, защита от спама). Размер: M.
